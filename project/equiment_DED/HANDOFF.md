### 1-1. 과제의 큰 그림 (양식 1 첫 단락에 그대로 인용 가능)

- 본 과제는 **미니어처 데이터 팩토리(Miniature Data Factory, MDF)** 구축을 기점으로 진행.
- MDF는 소재의 용해 → 압연·열처리 → 물성·미세조직 자동 측정의 일련 자동화 시스템.
- 핵심 지원 테마 3가지:
  1. **그린수소 생산용 촉매**
  2. **가스터빈 부품용 합금소재**
  3. **고탄성 주조용 알루미늄 합금**
- 추진체계: MDF 구축(시작) → 데이터 표준화 → DB 구축 → 소재 설계 AI / 공정 최적화 AI → AI 서비스 플랫폼 개발 → 중소·중견 기업 지원.

### 1-2. ⚠ 사용자 미제공 / 본인 직접 확인 필요 항목

1. **최종 계획서 v0.8 PDF** — 첨부되지 않음. 과제 최종목표 정확 인용 위해 사용자에게 재요청 필요.
2. **장비구축연도 변경 사유** — 변경 전/후 연도가 사용자 입력 필요. 이전 사례(자동디지털 현미경)는 **2024 → 2023(잔여 예산으로 선도입)**. DED 3D 프린터의 변경 방향(예: 2024→2026 또는 2025→2026)은 사용자가 지정 필요.
3. **자체장비도입심의위원회 개최 결과** — 외부전문가 5인 이상 요건. 일시·장소·참석위원·심의결과(특이사항 포함)가 필요.
4. **수요조사 결과 (DED 3D 프린터)** — 신규 수요조사가 필요. 기존 GPU서버(31명, 2025.04.23~04.29)·자동디지털 현미경(22명, 2023.02.16~03.16) 구조 참조.
5. **사업기간 연장 여부** — 2025-12-31 종료 → 2026년 도입은 사업기간 연장 협약변경이 선행되어 있어야 함.

### 2-3. 구매규격서(공식 사양) — 심의요청서 "주요사양" 란에 그대로 사용

심의요청서는 InssTek MX-Fab을 직접 지목하지 않고 **사양 기반**으로 기술. 아래 9개 항목이 사양 중심 기술의 **표준 블록**.

#### 1) 3축 모션 시스템
- 구조: X, Y, Z Linear Gantry System
- Stroke: 450 × 450 × 300mm 이상
- 반복 정밀도: 50㎛ 이하

#### 2) 레이저 발진기
- 레이저 소자: Ytterbium Fiber Laser
- 파장 영역: 1,070nm ±10nm (Operating Mode: CW)
- 최대 출력(Max): 2,000Watt 동등
- Beam Core Size: 800㎛
- 출력 안정성: ±2% (최대 오차율 기준)
- 출력 제어범위: 10~100%

#### 3) 적층 헤드부
- 적층 방식: Laser Powder Directed Energy Deposition (LP-DED)
- 가변형 빔 스팟 시스템: 1,200 ~ 2,400㎛ (모듈교체 및 가변 제어 지원)
- IR 카메라 동축 광학 시스템: 레이저 경로와 일치하는 동축 설계 (Coaxial Design)
- 교체형 노즐 팁 구조: 유지보수 및 교체 편의성

#### 4) 가열 및 냉각 플레이트 시스템
- 가열 사양: 유효 영역 400 × 400mm / 최대 온도 400℃ 이상
- 냉각 사양: 수냉식 (Water-cooled), 냉각 능력 1,500W 이상

#### 5) 분말 공급 시스템
- 금속 분말 저장 장치(Hopper): 6개
- 금속 분말 저장 용량(1 Hopper 기준): 1.0L
- 금속 분말 공급 가능범위(for Ti-6Al-4V): 0.05 g/min ~ 60 g/min
- Feedback System: 실시간 분말 토출량 제어 가능 (오차 범위 ±10%)

#### 6) 공정 모니터링 및 제어 시스템
- DMT Closed-loop 제어: 적층 높이 실시간 모니터링 및 높이 보정 피드백
- 하드웨어/소프트웨어 통합: 실시간 공정 제어 전용 H/W 및 S/W 인터페이스 제공

#### 7) 장비 운용 및 CAM 소프트웨어
- OS: Windows 기반 전용 운영체제 및 Advanced HMI Program
- UI/UX: 터치스크린 기반 직관적 조작
- CAM: 시뮬레이션 및 충돌 감지, Slicing & Tool-path 생성
- 공정 제어: NC code 기반 다중 소재, 레이어별 분말/레이저/가스 파라미터 개별 설정

#### 8) 시스템 자동화 및 안전
- 시편 자동 핸들링: 적층 완료 후 자동 적재·보관 — 무인 운용
- 스마트 도어 시스템: Auto-Locking / Auto-Opening
- 안전 인터록: 비상 상황 실시간 연동, 통합 경보

#### 9) 환경 제어 및 오토 퍼징 시스템
- **별도 밀폐형 챔버 없이 고순도 Argon (>99.999%)을 공급하는 Non-chamber 구조**
- Auto-purging System: O₂ ≤ 50ppm 유지 (공급 가스 순도에 따름)

#### 10) 기타
- CE 안전인증
- 소재 공정 Parameter 20개 이상 제공
- 보증기간: 1년, 영구 소프트웨어 기술지원

### 2-4. 핵심 차별 사양 3개 (사양 중심 기술의 "묶음")

심의요청서 본문과 변경사유서에서 **"왜 이 장비여야 하는가"**의 핵심 논거. 국내외 LP-DED 장비 중 동시 만족 모델이 매우 제한적임:

1. **6채널 이상 독립 분말공급 + 실시간 피드백 ±10%** → 단일 공정 내 합금 조성 연속 가변 (CGM, High-throughput 합금 탐색)
2. **Non-chamber Auto-purging (O₂ ≤ 50ppm)** → 챔버 퍼징 대기시간 제거, 시편 회수 사이클 단축
3. **무인 시편 자동 핸들링 + 스마트 도어 + DMT Closed-loop** → MDF 무인 데이터 생성 파이프라인 직결

이 세 가지를 묶어 "MDF 무인 합금 조성 탐색에 필수"로 논리화하면, 사양 중심으로 기술하면서도 사실상 동급 장비를 특정 가능.

### 2-5. MDF 데이터 파이프라인에서의 위치

```
[조성·공정 데이터 생성]              [미세조직 데이터 생성]              [AI 학습]
DED 3D 프린터  ────────►  자동디지털 현미경(2023 구축)  ────────►  GPU서버(2025 구축, NFEC-2023-12-292089 연동)
(본 심의 대상)            (인장시편→미세조직→물성)              (생성형 AI 모델 학습)
       │                          │                                    │
       └──────────────────────────┴────────────────────────────────────┘
                                  │
                          MDF 통합 데이터베이스
                                  │
                          중소·중견 기업 지원 플랫폼
```

본 장비는 "조성·공정 데이터 생성" 단계를 담당. 6채널 독립 호퍼로 Composition Space를 단일 공정에서 연속 탐색하고, IR/DMT 모니터링으로 공정 파라미터-품질 데이터를 자동 라벨링하여 MDF DB에 직접 기여.

## 8. hwpx skill 작업 워크플로우

### 8-1. skill 미설치 시 작업 순서
1. **사용자에게 hwpx skill 업로드 요청** (zip 또는 SKILL.md 단독)
2. 받은 skill을 `/mnt/skills/user/hwpx/`에 복사
3. SKILL.md를 view로 열어 사용법 확인
4. skill에 명시된 패턴대로 hwpx 파일 생성
5. `/mnt/user-data/outputs/`에 최종 산출물 저장
6. `present_files`로 사용자에게 다운로드 링크 제공

### 8-2. skill이 없을 경우의 fallback
1. **DOCX로 작성** (`/mnt/skills/public/docx/SKILL.md` 사용) → 사용자 측 한글에서 hwpx로 저장
2. **HWPX = ZIP + XML** 구조이므로, 빈 양식 hwpx 템플릿을 사용자가 업로드해 주면 직접 XML 편집 가능. 단 표 셀병합·머리글 손상 위험 있음.

### 8-3. 작성 권장 순서 (의존성 고려)
```
① 심의요청 공문 (가장 단순)

○ 소재부품기술기반혁신사업 "금속소재 제조디지털혁신 플랫폼 구축" 과제는
  미니어처 데이터 팩토리(MDF) 구축을 기점으로 진행
- 구축 장비는 미니어처 데이터 팩토리의 핵심 요소 중 하나
- 본 장비를 도입함으로써 다음과 같은 목표 달성 가능:
   - 합금 조성·공정 데이터 자동 생성 (Compositionally Graded Materials)
   - 무인 시편 적층 → 미세조직 측정 → 물성 평가 파이프라인 자동화
   - 그린수소 촉매 / 가스터빈 합금 / 고탄성 알루미늄 합금 시편 신속 제작

○ Laser Powder DED 방식은 다종 분말의 독립적 실시간 혼합 공급이 가능하여,
  단일 공정 내 연속적인 합금 조성 가변 구현 → 소재 탐색 효율 극대화
- 인공지능 학습용 대량의 조성-공정-품질 데이터 확보가 가능
- IR 동축 카메라 + DMT 폐루프 모니터링으로 공정 파라미터-품질 자동 라벨링

○ 본 장비는 자동디지털 현미경(`23 구축, NFEC-XXXX-XX-XXXXXX) 및
  생성모델 훈련용 GPU서버(`25 구축)와 연동되어 MDF 통합 파이프라인을 완성함

(이미지 자리: MDF 파이프라인 다이어그램 — DED → 자동디지털 현미경 → GPU서버)

○ 따라서 "DED 방식 금속 3D 프린터"는 소재부품기술기반혁신사업
  "금속소재 제조디지털혁신 플랫폼 구축" 과제의 핵심 데이터 생성원으로
  사업 추진과 인공지능 모델 구축, 중소·중견 기업 지원에 필수적인 장비
```

## 11. 이전 사례 핵심 수치 (양식 4 가동률·유지보수 산식 작성 시 직접 참조)

### 11-1. 자동디지털 현미경 (2023 통과 사례, 88백만원)
- 수요조사: 22개 기업·기관 (2023.02.16~03.16, 비대면 SNS 조사)
- 연 7.55회 이상 사용 / 회당 18.68~25.95시간 (하루 8시간 계상, 최대 5일 제한)
- 연간 가동시간: 22기관 × 7.55회 × (18.68~25.95 + 1시간) = 3,269 ~ 4,476시간
- 예상 가동률: 163% ~ 224% (평균 194%)
- 이용기업 수: 최저 22 / 최대 32

### 11-2. 생성모델 훈련용 GPU서버 (2025 진행, 279백만원)
- 수요조사: 31명 (2025.04.23~04.29, 산·학·연 비대면)
- 연간 1인당 평균 사용 횟수: 4회
- 1회당 평균 가동시간: 53시간
- 평균 가동시간: 6,572시간/년 (31인 × 4회 × 53시간)
- 가용시간 250일(주5일×50주) 기준 예상 가동률: **328.6%**
- 3팀 동시 활용 보정 시: **109.5%**

### 11-3. 자동디지털 현미경 자체장비도입심의위 (2023.05.04 사례)
- 일시: 2023.05.04(금) 14:00 ~ 18:00
- 장소: 한국재료연구원 + 비대면 (리모트미팅)
- 참석위원: 내부위원 3인, 외부위원 6인 (외부 5인 이상 요건 충족)
- 심의 결과: 특이사항 없음

### 11-4. 자동디지털 현미경 도입연도 변경 (2024 → 2023)
- 사유: "구축 장비는 본 과제의 목표 중 하나인 조성-공정-물성-미세조직 데이터베이스 구축에 필수적. 미세조직 자동 분할(segmentation) AI 모델, 탄성계수·푸아송 비 등의 물성 예측 AI 모델 개발을 위해서는 빅데이터베이스 구축이 선행되어야 함. 위와 같은 이유로 2023년 잔여 예산으로 선 도입하고자 함."
