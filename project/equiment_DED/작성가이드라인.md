### 2-3. 색상 가이드

- 슬라이드 제목 노랑 (#FFFF00) — 양식 디자인 그대로 유지
- 강조 빨강 (#FF0000) — 양식의 ※ 안내문은 모두 **본문 작성 시 삭제**
- 본문은 검정(#000000) 기본
- 표 헤더 회색/연파란색 가능 (사례 참조)

### 2-4. 글머리 기호 체계

- **□** : 1단계 주제 (셀 헤더, 굴림 12~14pt B)
- **○** : 2단계 항목 (+mn-ea 14pt B)
- **-** : 3단계 세부 (+mn-ea 12~14pt B)
- **·** : 나열 (사용자 선호: **쉼표 위주, · 최소화**)
- **※** : 빨간 안내문 (양식의 작성 가이드, 본문 작성 시 삭제)

### 슬라이드 4. 사업(연구) 부합성 ①

```
□ 연구시설·장비의 구축의 필요성

○ 본 사업 "금속 소재 멀티모달 빅데이터 구축" 과제는 자동화 실험실(Automated Lab) 구축을 기점으로 진행
  - 자동화 실험실: "설계된 절차를 로봇과 자동화 장비가 수행하는 실험실" (계획서 v0.8 p.1)
  - 본 DED 3D 프린터는 자동화 실험실의 **제조 모듈 핵심 장비** (1차년도 도입)

○ 본 장비를 도입함으로써 다음 목표 달성 가능:
  - 다종 원소 합금의 분율 실시간 조정을 통한 합금 조성 가변 시편 자동 제작
  - FCC 단상 → FCC-BCC 다상 상경계 → 준안정 석출 강화 합금에 이르는 소재 탐색 데이터 축적
  - 단상 합금 100개 조성 군에 대한 쿠폰사이즈 테스트 데이터 자동 확보

○ Laser Powder DED 방식은 다종 분말의 독립적 실시간 혼합 공급이 가능하여,
  단일 공정 내 연속적인 합금 조성 가변을 구현 → 소재 탐색 효율 극대화
  - 6채널 독립 분말 호퍼 + 실시간 토출량 피드백 (±10%) → CGM (Compositionally Graded Materials) 구현 인프라
  - IR 동축 카메라 + DMT Closed-loop 모니터링으로 공정 파라미터-품질 자동 라벨링

○ 본 장비는 자동화 실험실의 다른 모듈 (와이어 컷 가공기, 멀티채널 자동 열처리로, 자동 경도 측정기, XRD 자동화, SEM/EBSD/EDS, 다목적 로봇팔 매니퓰레이터) 과 유기적으로 연동되어 25,000건의 멀티모달 데이터 생산 파이프라인을 완성

(이미지 자리: 자동화 실험실 모듈 도식 — DED 3D 프린터 (1차년도, 본 심의대상) → 와이어 컷, 열처리로, 경도, 분말 호퍼 (2차년도) → XRD, 연마, SEM, EBSD, EDS (3차년도) → 통합 자동화 (4~5차년도))

○ 따라서 "DED 방식 금속 3D 프린터"는 본 과제 "금속 소재 멀티모달 빅데이터 구축"의 핵심 데이터 생성원으로, 사업 추진과 금속 소재 파운데이션 모델 학습, 국내 소재 산업 디지털 전환에 필수적인 장비
```

- **이미지 자리**: 자동화 실험실 5개년 장비 구축 로드맵 (계획서 p.11 표 참조)

## 9. 가동률·유지보수비 산식 가이드

### 9-1. 가동률 산식 (수요조사 31명 기반)

**기본 산식 (NFEC 표준 양식)**:
```
가동률(%) = 연간가동시간 (실질가동시간 + 부대시간) / 연간가동가능시간 (2,000시간) × 100
```

본 장비는 **24시간 무인 운용 가능 (자동 시편 핸들링)**이므로 산정 시 두 가지 방안 가능:
- (A) NFEC 표준 가용시간 2,000시간 (8시간 × 250일) 적용
- (B) 24/7 가용시간 8,760시간 적용

⚠ KIAT 담당간사와 협의 후 결정.

**수요조사 31명 기반 산출 (예시 — 정확한 값은 엑셀 데이터 기반 재계산)**:
```
연간 1인당 평균 사용 횟수 ≈ (1회×3 + 5회×9 + 10회×8 + 15회×11) / 31명 ≈ 8회/인
1회당 평균 가동 시간 ≈ (4시간×2 + 8시간×9 + 24시간×3 + 72시간×9 + 240시간×8) / 31명 ≈ 89시간/회
연간 예상 가동시간 = 31인 × 8회 × 89시간 ≈ 22,072시간/년

(A) 가용시간 2,000시간 기준 → 가동률 ≈ 1,103% (외부 수요만, 내부 자동화 실험실 운용 미반영)
(B) 가용시간 8,760시간 (24/7) 기준 → 가동률 ≈ 252%
```

> **결론**: 어느 방식을 적용해도 100% 이상의 가동률 확보. 자동화 실험실 통합 운용으로 24/7 무인 운용 → 가동률 충분.

### 9-2. 유지보수비 산식 (NFEC MANUAL No.17 기반)

**기본 산식**:
```
연간 유지보수비 = 장비 취득가액(원) × 유지보수요율(%)
```

**본 장비 분류 후보**:
- C. 기계가공·시험장비 / C.34 자동화장비 (3.51% 중대형) — 자동화 실험실 모듈 관점
- C. 기계가공·시험장비 / C.0 달리분류되지 않는 기계가공·시험장비 (4.04% 중대형)
- C. 기계가공·시험장비 / C.55 조립장비 (3.86% 중대형) — 적층제조의 조립 관점

⚠ **사용자 확인 필요**: KIAT 담당간사와 분류 코드 확정. 통상 적층제조 장비는 별도 명시 분류가 없어 "C.0 달리분류되지 않는 기계가공·시험장비" 또는 "C.34 자동화장비" 적용 가능.

**유지보수비 계산 (12.54억, 중대형 기준)**:
```
- C.34 자동화장비 (3.51%): 1,254,000,000 × 3.51% = 약 44,015천원/년
- C.0 달리분류되지 않는 기계가공·시험장비 (4.04%): 1,254,000,000 × 4.04% = 약 50,662천원/년
- 평균: 약 47,000천원/년 (4,700만원/년)
```

**시간당 이용료 산정 (NFEC 「연구시설장비 이용료 산정기준」)**:
```
시간당 이용료 = 이용단가 + 직접비/시간 + 간접비/시간
```
GPU서버 사례 (2025): 시간당 80,000원 / 연간 유지보수비 10,825천원 / 연간표준활용시간 1,400시간 / 유지보수요율 4.33% (중형)
