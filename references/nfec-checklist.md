## 1. 심의대상 분류 (구축비용 기준)

| 구축비용 | 심의 주체 | 추가 의무서류 |
|---|---|---|
| ~3천만원 미만 | 기관 자율 (자산관리) | — |
| 3천만 ~ 1억 미만 | 연구개발과제평가단 또는 자체심의위원회 | 비교견적서 2건+ |
| **1억 ~ 10억 미만** | **국가연구시설장비심의위원회** | 비교견적서 2건+ |
| **10억 ~ 50억 미만** | 국가심의위원회 | + **사전기획보고서 (별표 6) 필수** |
| 50억 ~ 500억 미만 | 국가심의위원회 + 사전검토 회의 | 사전기획보고서 + 사전검토 |
| 500억 이상 | 국가심의위원회 + 예비타당성조사 | + 예비타당성 조사보고서 |

→ **항상 구축비용 먼저 확인**. 1억 이상이면 국가심의위원회, 10억 이상이면 사전기획보고서 필수.

## 2. 8개 심의기준 본문 충족 체크리스트 (세부지침 2.4.2)

각 항목에 본문이 작성되어야 통과 가능. ※ 안내문만 남기지 말 것.

### ☐ 사업(연구) 부합성
- [ ] 구축장비가 사업(연구)과 어떻게 부합하는지 명시
- [ ] 도입 시기가 사업기간 고려 시 적정한지 명시
- [ ] 사업(연구) 수행에 반드시 필요한지 명시
- [ ] 정부 예산 지원으로 구축이 타당한지 명시

### ☐ 국가전략적 필요성
- [ ] **NFRM (국가대형연구시설구축지도)** 연계성 명시
- [ ] **과학기술기본계획** 연계성 명시
- [ ] **국가R&D중장기 투자계획** 연계성 명시
- [ ] 소관 중앙행정기관의 중·장기 R&D 계획 연계성 명시
- [ ] 과학·기술·경제·사회적 측면 국가위상·경쟁력 제고 시급성 명시

### ☐ 연구시설장비의 중복성
- [ ] **ZEUS RED 중복성 검토확인서 발급 + 첨부** (필수)
- [ ] 동일·인근지역(5+2 광역경제권), 동일기관 內 보유 여부 명시
- [ ] 동일·유사 장비 있을 시 차별성·추가 수요 명시
- [ ] 중복성 예외 인정 사유 (특수환경/활용성 확보/시급성/전국 수요) 해당 시 명시

### ☐ 연구시설장비의 활용성
- [ ] 해당 사업에서 활용도 높음 명시
- [ ] 사업 종료 후 타 사업/기관 활용 가능성 명시
- [ ] 기관 내 집적화 기능 + 직접화 계획 구체적 명시
- [ ] **명확한 근거 기반 구체적 활용도(률) 정량 제시** (예: 연간 ___시간, 외부 활용 ___%)

### ☐ 연구시설장비의 적정성
- [ ] 연구목적 달성 적합한 사양·성능 명시
- [ ] **외산 구매 시 국산 검토 필수** — 검토 결과 본문 명시
- [ ] 신청 수량 2개 이상 시 타당한 이유 명시

### ☐ 연구시설장비 운영의 계획성
- [ ] 전담인력·전문성 확보 방안 (성명·소속·학위·고용형태·담당장비수) 표 명시
- [ ] 연구과제 종료 후 합리적 운영(활용) 계획 명시
- [ ] **설치 공간 안전기준 검토 결과** 본문 명시 (필증 첨부 권장)
- [ ] 운영비(인건비·유지보수비·소모품비) 확보방안 명시

### ☐ 도입 기관의 관리실태 (자주 누락됨)
- [ ] 처분절차 준수 여부 명시 (제41~44조)
- [ ] 유휴 연구시설장비 보유 및 관리 현황 명시
- [ ] 시설장비책임관 + 전담조직 운영 명시 (제8~10조)
- [ ] 기관 자체심의위원회 운영 실적 명시

### ☐ 구축비용의 적정성
- [ ] **제조사가 다른 2개 이상의 비교견적서 첨부** (필수)
  - 또는 **단일견적 사유서** (4가지 中 하나 입증) — 사양 충족 1인뿐 / 특허 등록 / 긴급 / 신속도입 인정
- [ ] 견적서는 6개월 이내, 세부 구성품명+구성품별 금액 명시 (총금액만 제시 시 불인정)

## 4. 사전기획보고서 12항목 (10억 이상 필수, 별표 6)

1. 연구시설·장비 개요 (국·영문명, 구분, 분류, 용도, 사양, 모델명)
2. 연구시설·장비 필요성 (사업목적 부합성 + 국가적 필요성, NFRM 연계)
3. 구축 현황 (국내·외)
4. 차별성 (특화된 부분, 새로운 기능)
5. 수요조사 현황 (목적·내용·결과)
6. 도입 적정성 (도입방법 + 금액)
7. 단계별 구축 계획 (구축환경, 안전확보조치, 안전필증서류 첨부)
8. 운영계획 (운영재원, 운영인력 배치·확보)
9. 활용계획 (활용목표, 단독/공동활용 계획, 공동활용 불가시 사유 + 증빙)
10. 기대효과 (과학기술/경제/사회/지역적 측면)
11. 작성 절차 + 참여인력
12. 기타

## 5. 활용범위 분류 (표준지침 §3, 별표 2)

### 단독활용 판정기준 (8개 中 1개 이상 충족)

1. 연간 2,000시간 이상 활용 (자체수요多)
2. 시작품·시제품 시험운영 중
3. 특수목적용 자체 특화
4. 24/7 상시 모니터링
5. 국가안보·기술유출 보안
6. 위험물질·고위험성 이용 제한
7. 초고감도 정밀장비
8. 라이선스 계약으로 타 이용자 사용 불가

→ **단독활용 vs 공동활용 정합성** 점검: 같은 문서 內에서 단독으로 명시했다 공동으로 명시하면 안됨.

| 결과 | 의미 | 후속 |
|---|---|---|

## 7. 검증 자동화 체크리스트

# verify_nfec.py 의사 코드
checks = {
    "8_criteria_filled": all(criterion_text and len(criterion_text) > 50
                             for criterion_text in [사업부합성, 국가전략, 중복성,
                                                     활용성, 적정성, 운영계획, 관리실태, 구축비용]),
    "estimates_attached": (비교견적서_count >= 2) or (단일견적_사유서_exists),

    "nfrm_mentioned": "NFRM" in 국가전략 or "국가대형연구시설구축지도" in 국가전략,
    "domestic_review": (국산_장비) or ("국산 검토" in 적정성),
    "safety_review": "안전기준" in 운영계획 or "안전필증" in 운영계획,
    "zeus_red_attached": ZEUS_중복성검토확인서_exists,
    "utilization_quantified": re.search(r"\d+\s*시간", 활용성) is not None,
    "estimates_recent": all(견적서_date > now - 6_months for 견적서_date in 견적서들),
    "estimate_breakdown": all("총금액"_only is False for 견적서 in 견적서들),
}
assert all(checks.values()), f"미충족 항목: {[k for k,v in checks.items() if not v]}"

## 8. 자주 누락되는 항목 (실무 함정)

1. **NFRM 직접 인용** 없이 "국가전략기술" 만 언급 — 부족
2. **외산 검토 시 국산 검토 결과** 본문 없음 — 적정성 항목 미달
3. **안전기준 검토** 본문 없음 — 운영계획성 항목 미달
4. **관리실태** 항목 자체를 누락 — 가장 자주 빠짐
5. **활용도 정량 표현 없이** "활용도 높음" 만 명시 — 활용성 항목 약함
6. **단독 vs 공동활용 분류 정합성** 불일치 — 문서 內 모순
7. **견적서가 총금액만 제시** — 구성품별 금액 없으면 불인정
8. **본심의 vs 상시심의 구분 불명확** — 상시심의 시 사유 소명 필요
