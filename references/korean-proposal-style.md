# 국내 R&D 연구과제 제안서 문체/형식 가이드

출처: `master_refrerence/` 내 통과 제안서 4건 분석 (KIST 반도체, 에기연 수소, 글로벌 TOP CCU, hw 소재AI)

## 1. 구조 패턴

- 로마자 대장(Ⅰ, Ⅱ, Ⅲ) → 아라비아 절(1, 2) → 소절(1-1)
- 4단계 bullet 계층: `□ 대제목` → `○ 중항목` → `-` 소항목 → `※` 참고/단위
- 모든 페이지에 표 또는 도식 1개 이상. 텍스트:그래픽 ≈ 50:50
- 섹션 첫머리에 "총괄목표 → 비전 → 핵심성과목표 → 실행목표" 계단 구조

## 2. 문체 (매우 중요)

### 2-1. 개조식이 기본, 통문장 회피

```
○ (개조식 권장) 핵심기술 확보: 대용량, 저비용, 고효율 수전해 핵심기술 확보
○ (서술식 회피) 본 연구에서는 대용량 수전해 핵심기술을 확보하고자 합니다.
```

### 2-2. 명사형 종결 (동사·서술형 회피)

| 회피 | 권장 |
|------|------|
| ~할 계획임, ~하고자 함 | ~확보, ~개발, ~구축, ~제시, ~도출 |
| ~하는 것을 목표로 함 | ~목표 |
| ~진행 중에 있음 | ~진행 중 |
| ~할 예정임 | ~예정 |
| ~할 수 있음 | ~가능 |

### 2-3. 짧은 호흡, 1문장 1아이디어

- 한 bullet 20~60자 내외
- 통문장은 최대 3줄

### 2-4. 구분자

- 나열은 **쉼표(,)** 위주 (사용자 선호). · 는 한정적 용법
- "A, B, C 등" 형식

## 3. 권장 어휘

### 성과형 명사
- 확보, 도약, 제시, 구축, 선도, 실현, 창출, 고도화

### 필요성 강조
- 시급, 절실, 필수, 핵심, 전주기, 주권 확보

### 정부 키워드 (자연스럽게 섞어 쓰기)
- 12대 국가전략기술, 탄소중립, 글로벌 TOP, 기술주권, 기술자립, 기술격차, 퍼스트무버, 산업생태계

### 연구 패러다임
- closed-loop, human-in-the-loop, 자율화, 지능화, 연계·융합, 고속·대량

## 4. 정량화

- 모든 목표는 숫자로 수식: "~%, ~년, ~억원, ~M급, ~단계"
- 단계별 일정은 "1단계('24~'25)", "2단계('26~'28)" 형식
- 선도국 대비 기술격차를 연 단위로 명시

## 5. 시각적 배치

- 개념도 / 조직도 / 로드맵 / 4분면 전략도
- 표는 "구분/내용/주요산출물/담당기관" 형식

## 6. 분량 계산

- 대형 사업(100+억): 150~300페이지
- 소형/GPU 과제 같은 짧은 붙임: 4페이지 내외, 글자 12pt 기준
  - 짧은 양식은 개조식이 생존의 문제 (통문장 쓰면 분량 초과)

## 7. 우리 GPU 과제에 적용할 핵심

1. 표 셀 안의 문장을 **명사형 종결**로 정리 ("~할 예정" → "~확보")
2. **개조식 불릿(○, -) 활용** (붙임 본문에서)
3. **쉼표 위주** 구분 (· 지양)
4. **정량 표기 강화**: "기술격차 N년", "소재 후보 N개", "공정 변수 N개" 등
5. 정부 키워드 자연스러운 삽입 ("기술주권 확보", "12대 국가전략기술 중 AI" 등)
